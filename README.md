# Forma — Treatment Studio

Interactive dental treatment and financing prototype. All patients, providers, lenders, offers, payments and appointments are fictional. No real credit checks or transactions occur.

## Demo

- Coordinator workspace with five sample cases
- Patient treatment and payment walkthrough
- Adjustable down payments and illustrative financing comparisons
- Phased treatment, partial approval and no-offer outcomes
- Simulated scheduling and refund reconciliation

Plain HTML, CSS and JavaScript. No backend or build step. Demo state resets on refresh.

## GitHub Pages

Publish from the `main` branch and `/ (root)` folder in Settings → Pages.

## Local preview

Run `python3 -m http.server 8782` from this directory, then open http://localhost:8782.
